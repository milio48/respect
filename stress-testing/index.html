🧪 Pusat Uji Interaktif (Quick Runner)

Semua aksi yang membutuhkan klik, dialog, atau interaksi dikumpulkan di satu tempat ini. Jalankan per-aksi memakai tombol Jalankan, atau tekan ▶ Jalankan Semua (Otomatis) untuk mengeksekusi seluruh uji aman secara berurutan. Setiap hasil otomatis tercatat di log dan ikut diekspor ke laporan (JSON / Markdown / Log Mentah).

Aksi bertanda DIALOG membuka alert/confirm/prompt/popup native. Aksi bertanda HAZARD (misalnya window.open) dapat menimpa window utama atau membekukan aplikasi pada engine embedded ini — aksi HAZARD tidak pernah dijalankan oleh tombol Run All, hanya bisa diklik manual satu per satu. Siapkan restart aplikasi sebelum mencobanya dan catat hasilnya di kolom Catatan.
